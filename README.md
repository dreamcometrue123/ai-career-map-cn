# AI职业地图 · Career Atlas

移动端优先的AI职业转型探索工具，收录70个岗位方向和14个职业类别，包含财务、市场、销售、文案、内容生成与职能运营转型。

- 输入职业背景、已有能力与工作偏好，查看有依据的转型方向。
- 推荐展示能力线索、待核实技能和经验限制，不展示录用概率。
- 支持岗位搜索、分类、详情和本机收藏。
- 招聘入口仅使用具体职位详情；暂无直达链接时，单独展示公司线索及其来源。历史职位状态需到原平台核实。
- 转型方向展示可自动化任务与人工职责，不代表整个职业会被替代，也不代表已核实在招。

## 本地运行

使用 Node.js 22.13 或更新版本：

```sh
npm ci
npm run dev
```

运行 `npm test` 检查匹配边界，运行 `npm run build` 生成 `dist/` 静态网站。

## 发布

仓库 Settings → Pages → Source 选择 GitHub Actions。推送到 main 后自动构建和发布。
静态资源使用相对路径，可部署到 GitHub Pages 的项目子目录。

## 数据和隐私

能力匹配是本地规则计算，未接入大模型或后端数据服务。职业输入保留在当前页面内，刷新后清空；收藏只存储在当前浏览器，不会跨设备同步。70个岗位方向不是完整职业分类，也不代表70个正在招聘的职位。

## 维护

岗位数据：`app/career-data.ts`；匹配逻辑：`app/matching.ts`；界面：`app/page.tsx`；样式：`app/globals.css`。
本仓库为独立公开版本，不包含原托管平台的账号配置、访问凭据或私有Git历史。
